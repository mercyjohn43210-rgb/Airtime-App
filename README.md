# Johnmercy Data & Airtime

A responsive demo airtime/data web app created for the project.

## Files
- `index.html` — app interface
- `style.css` — responsive styling
- `app.js` — demo login, wallet, airtime/data forms and transaction history

## Important
This is a front-end demo. It does not process real money or deliver real airtime/data. A production version needs a secure backend, database, authentication, payment gateway and a licensed VTU/data API.
